충남 내신 계산 기준

이 웹앱은 충청남도교육청의 중학교 내신성적 산출 방식을 기준으로 계산합니다.

다른 시·도에서는 과목별 반영 방법이나 내신 계산 기준이 다를 수 있습니다. 실제 고등학교 입학전형에 사용할 때는 학교 또는 해당 교육청의 최신 안내를 반드시 확인해 주세요.

이 웹앱의 계산 결과는 학습 계획을 세우기 위한 참고 자료이며, 학교에서 공식적으로 발급하는 성적을 대신하지 않습니다.

내 정보는 어디에 저장되나요?

입력한 과목, 평가계획, 점수와 목표점수는 현재 사용 중인 브라우저 안에만 저장됩니다.

  • 별도의 서버로 전송하지 않습니다.
  • 운영자가 학생의 성적을 수집하거나 보관하지 않습니다.
  • 로그인이나 회원가입이 필요하지 않습니다.
  • 같은 기기와 브라우저를 다른 사람과 함께 사용하면 입력 정보가 보일 수 있습니다.

공용 컴퓨터를 사용한다면 이용 후 데이터를 직접 삭제하는 것이 안전합니다.

기기나 브라우저를 바꿀 때

브라우저에 저장된 데이터는 다른 기기나 브라우저로 자동 이동하지 않습니다.

기기를 바꾸기 전에 사이드 패널의 데이터 백업을 눌러 백업 파일을 저장하세요. 새 기기에서는 복원을 눌러 백업 파일을 선택하면 기존 데이터를 다시 불러올 수 있습니다.

백업 파일에는 입력한 성적 정보가 포함되므로 다른 사람에게 보내거나 공개하지 마세요.

데이터가 사라질 수 있는 경우

  • 인터넷 사용 기록이나 사이트 데이터를 삭제한 경우
  • 브라우저를 초기화하거나 삭제한 경우
  • 시크릿 모드나 비공개 모드를 사용한 경우
  • 다른 브라우저나 다른 기기에서 접속한 경우

중요한 성적을 입력했다면 주기적으로 백업 파일을 내려받아 보관하는 것을 권장합니다.

계산 결과를 확인해 주세요

평가계획으로 계산한 원점수와 성취도는 예상값이며, 학교생활기록부의 실제 성적과 다를 수 있습니다.

충남 교과 내신을 정확하게 확인하려면 학교생활기록부의 확정 원점수와 성취도를 입력해 주세요.
